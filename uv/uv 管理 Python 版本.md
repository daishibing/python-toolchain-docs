# uv 管理 Python 版本

使用 uv 可以轻松管理多个 Python 版本

# 常用命令

查看可用的 Python 版本：

```shell
uv python list
```

查看已安装的 Python 版本：

```shell
uv python list --only-installed
```

安装 Python：

```shell
uv python install 3.12
```

卸载 Python：

```shell
uv python uninstall 3.12
```

查看 Python 安装目录：

```shell
uv python dir
```
